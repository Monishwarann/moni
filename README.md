## 🌟 Overview

This repository contains the source code for the personal portfolio website of **Monishwaran K**, a Third-Year B.E. Mechanical Engineering student at **Meenakshi Sundararajan Engineering College** who bridges the gap between hardware logic and software innovation.

Built with **React 18**, **TypeScript**, **Vite**, and **Tailwind CSS**, the portfolio features glassmorphism UI design, interactive 3D elements, dynamic radar charts, animated project showcases, real-time contact transmission via Formspree, and verification links for certifications and achievements.

---

## 🛠️ Technology Stack

### **Frontend & UI**
- **Core Library**: React 18 & TypeScript
- **Build Tool**: Vite 5
- **Styling**: Tailwind CSS, `@tailwindcss/typography`, `tailwindcss-animate`
- **Animations & Visuals**: Framer Motion, GSAP, Lucide React
- **3D & Canvas**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Components & UI System**: Radix UI primitives, Shadcn UI components, Sonner, React Hot Toast
- **Data Visualization**: Recharts, Tech Stack Radar

### **Backend, Data & Cloud Integrations**
- **Database & Auth**: Supabase (`@supabase/supabase-js`)
- **Email & Forms**: EmailJS (`@emailjs/browser`), Formspree API integration
- **State Management**: TanStack React Query (`@tanstack/react-query`), React Hook Form (`react-hook-form`, `zod`)

## ⚡ Getting Started Locally

### Prerequisites
Make sure you have **Node.js** (v18 or higher) and **npm** (or **bun**) installed on your machine.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Monishwarann/moni.git
   cd moni
   ```

2. **Install dependencies**:
   ```bash
   npm install
   # or
   bun install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   # or
   bun dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
